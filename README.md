# Debt-Loop: 3D Roguelike Puzzle Game

## 📌 Overview
**Debt-Loop** is a unique 3D roguelike puzzle game developed in Unity. Players must gamble N times to clear the room maintaining their HP and a positive balance.

## ⌨️ Controls
* <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> — Move
* <kbd>T</kbd> — Teleport to dungeon
* <kbd>I</kbd> — Open inventory
